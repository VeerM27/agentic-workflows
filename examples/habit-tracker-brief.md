# Habit tracker

A small, friendly web app for tracking daily habits.

- Users add habits (name, optional emoji, target days per week).
- The home screen shows today's habits as a checklist; tapping one marks it done for today.
- A weekly view shows a 7-day grid per habit and the current streak.
- Data stays in the browser (localStorage); no accounts, no backend.
- It should feel calm and encouraging, not gamified. Works well on a phone.
